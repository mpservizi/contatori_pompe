# ⛽ Gestione Contatori Impianto Carburanti

Web app per la gestione dei contatori di un impianto carburanti (SSP, Diesel, GPL), ottimizzata per uso su smartphone e tablet e installabile come PWA.

Il sistema è pensato per uso reale da parte degli operatori di un distributore.

---

# 🚀 Funzionalità

## 📊 Contatori digitali

- 7 cifre per ogni pompa
- Inserimento tramite incrementi/decrementi per singola cifra
- Contatori separati:
  - PRIMA (inizio turno)
  - DOPO (fine turno)
- Differenza automatica in litri

---

## ⛽ Impianto fisso

```js
SSP:    Pump 1, Pump 2
Diesel: Pump 3, Pump 4, Pump 5, Pump 6
GPL:    Pump 7, Pump 8
```
